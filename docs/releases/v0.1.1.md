# cg50-espmod v0.1.1

Release centrada en el mod físico, CasioWIFI y el firmware común.

## Cambios

- Reparado el conflicto entre reconexión automática y escaneo Wi-Fi.
- Reintentos acotados cuando la radio devuelve estado ocupado.
- Cancelación y timeout liberan siempre el estado de escaneo.
- CasioWIFI conserva el error visible durante consultas de estado en segundo plano.
- El instalador solo reemplaza CasioWIFI y deja intactos los demás add-ins.
- CasioGPT pasa a su
  [repositorio independiente](https://github.com/samilososami/CasioGPT).

## Artefactos

- `CASIOWIFI.g3a`
- `cg50-espmod-esp32-app.bin`
- `cg50-espmod-esp32-merged.bin`
- `checksums.txt`

La imagen fusionada se flashea desde `0x0`. La imagen de aplicación se usa para
actualizar únicamente la partición correspondiente cuando el esquema de
particiones ya es compatible.

Probado en una Casio fx-CG50 y una Seeed Studio XIAO ESP32-C3. Consulta el
README y la guía de cableado antes de soldar o flashear.
