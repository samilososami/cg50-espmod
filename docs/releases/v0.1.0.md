Primera release pública y reproducible del mod fx-CG50 + XIAO ESP32-C3.

> **Release histórica combinada.** Desde v0.1.1, el mod base y CasioWIFI se
> mantienen aquí, mientras que CasioGPT se publica en
> [`samilososami/CasioGPT`](https://github.com/samilososami/CasioGPT).

Incluye:

- `CASIOWIFI.g3a`: escaneo, conexión y persistencia de redes Wi-Fi.
- `CASIOGPT.g3a`: chat con streaming mediante Ollama Cloud.
- `cg50-espmod-esp32-app.bin`: imagen de aplicación del firmware.
- `cg50-espmod-esp32-merged.bin`: imagen completa para flashear desde `0x0`.
- `checksums.txt`: SHA-256 de todos los artefactos.

El firmware es común a ambos add-ins, usa hostname `casio-cg50` y protocolo
UART v5. La API key no está incluida en los binarios: debe guardarse localmente
como `casiogpt_api.txt` en la raíz de la calculadora.

Consulta el README antes de soldar o flashear. Esta revisión se ha probado en
una Casio fx-CG50 y una Seeed Studio XIAO ESP32-C3.
