# cg50-espmod v0.1.2

Release de fiabilidad para clientes conectados como CasioGPT.

## Cambios

- Comprobación HTTPS en una tarea independiente con hasta diez intentos.
- Progreso `NET_WAIT:<id>:<intento>:10` compatible con clientes anteriores.
- `STATE` y `NET_BEGIN` adelantan la reconexión de una red guardada en lugar de
  esperar al temporizador de fondo.
- Motivos finales diferenciados: `NO_WIFI`, `NETWORK` y `SESSION`.
- Una petición repetida adopta la comprobación existente y no crea otra tarea.
- Pruebas de host para éxito en el décimo intento, agotamiento y recuperación de
  Wi-Fi.

## Artefactos

- `CASIOWIFI.g3a`
- `cg50-espmod-esp32-app.bin`
- `cg50-espmod-esp32-merged.bin`
- `checksums.txt`

La imagen fusionada se flashea desde `0x0`. La imagen de aplicación actualiza
solo la partición cuando el esquema instalado ya es compatible.
